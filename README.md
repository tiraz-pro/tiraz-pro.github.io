# tiraz.pro

الموقع الرسمي لـ **طراز للتشطيبات والمقاولات** — تشطيبات تسليم مفتاح للوحدات
السكنية في القاهرة الجديدة، متخصصة في خدمة المصريين المقيمين خارج مصر.

موقع ثابت (Static) بالكامل — HTML و CSS و JavaScript فقط.
لا سيرفر، لا قاعدة بيانات، لا مفاتيح.

## الصفحات

| الملف | الصفحة |
|---|---|
| `index.html` | الرئيسية |
| `remote.html` | نظام الرقابة عن بُعد |
| `pricing.html` | الشفافية المالية |
| `gallery.html` | معرض التصاميم |
| `calculator.html` | حاسبة الميزانية |
| `blog.html` | المدوّنة |
| `article.html` | عرض المقال — `article.html?a=SLUG` |
| `contact.html` | تواصل واحجز مكالمة |
| `404.html` | صفحة الخطأ |

## النشر

يُنشر تلقائياً عبر **GitHub Pages** من الفرع `main` (الجذر).

- `CNAME` → `tiraz.pro`
- `.nojekyll` → يمنع معالجة Jekyll
- `robots.txt` · `sitemap.xml` → للفهرسة

سجلات DNS المطلوبة عند مسجّل النطاق:

```
A      @     185.199.108.153
A      @     185.199.109.153
A      @     185.199.110.153
A      @     185.199.111.153
CNAME  www   tiraz-pro.github.io
```
